# util/ — utilidades compartidas de bajo nivel

[English](README.md) | Español

Estos paquetes sin dependencias proporcionan primitivas pequeñas compartidas por varias familias de capacidades. La semántica de negocio permanece en cada capacidad que los consume.

| Paquete | Rol |
|---|---|
| [`brand/`](brand/README.es.md) | Proporciona tipos con brand nominal |
| [`paths/`](home-paths/README.es.md) | Resuelve la raíz de datos del Harness y las rutas compartidas |
| [`timeout/`](timeout/README.es.md) | Proporciona primitivas de clasificación de plazos y timeouts |
| [`retention/`](output-retention/README.es.md) | Acota las colecciones retenidas de texto y de elementos |
| [`atomic-write/`](atomic-write/README.es.md) | Reemplaza archivos atómicamente |
| [`native-command/`](native-command/README.es.md) | Ejecuta comandos nativos del host sin shell |
