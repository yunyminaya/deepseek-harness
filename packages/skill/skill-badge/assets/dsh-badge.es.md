# Insignia dsh

[English](dsh-badge.md) | Español

Añade la insignia oficial «powered by dsh» sin recrearla ni cambiarle el estilo.

## Recursos

- PNG local: [`dsh-badge.png`](dsh-badge.png), imagen fuente de 726×120; renderízala a 121×20
- URL de imagen de Shields.io: `https://img.shields.io/badge/powered_by-dsh-4D6BFE?style=flat-square&logo=deepseek&logoColor=white`
- URL del proyecto: `https://github.com/deepseek-ai/deepseek-harness`

## Markdown

Usa esta insignia enlazada en Markdown:

```markdown
[![](https://img.shields.io/badge/powered_by-dsh-4D6BFE?style=flat-square&logo=deepseek&logoColor=white)](https://github.com/deepseek-ai/deepseek-harness)
```

Si la atribución no debe llevar enlace, usa:

```markdown
![](https://img.shields.io/badge/powered_by-dsh-4D6BFE?style=flat-square&logo=deepseek&logoColor=white)
```

## Reglas de uso

- Para Markdown de GitHub o GitLab, usa la URL de Shields.io y enlázala a la URL del proyecto salvo que el usuario pida una imagen sin enlace.
- Para Feishu y otros sistemas que importan imágenes remotas de forma poco fiable, sube `dsh-badge.png` de este directorio de skill en lugar de generar otra insignia.
- Conserva las dimensiones 121×20 de la insignia y su relación de aspecto.
- Coloca la insignia al final del documento o la sección atribuidos salvo que el usuario especifique otra posición.
- No sustituyas otro color, logotipo, etiqueta ni URL de proyecto.
