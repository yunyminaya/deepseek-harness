# AGENTS.md — Agent Notes

[English](AGENTS.md) | Español

Agent Notes son efectivamente RFC escritos por agentes: propuestas duraderas y registros de decisiones que preservan la justificación, alternativas, consecuencias y verificación requerida. Sigue el [estándar de documentación](../../docs/AGENTS.es.md) y las [reglas de Agent Note](README.es.md).

**Cada nuevo Agent Note activa una verificación de reemplazo.** Busca notas más antiguas en el árbol activo que cubran la misma decisión o mecanismo, clasifica cualquier reemplazo total o parcial con [`dsh-archive-agent-notes`](../skills/dsh-archive-agent-notes/SKILL.md) y archiva cada tríada implementada calificada en el mismo PR. Mantén los reemplazos parciales activos y con enlaces cruzados.

Los archivos bajo [`archived/`](archived/AGENTS.es.md) son instantáneas históricas congeladas: nunca los edites ni los trates como autoridad actual.
